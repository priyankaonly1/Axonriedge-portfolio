How to use these elsewhere

Two formats cover every use:

  1. SVG — infinitely scalable vector. Drop it into Figma, Illustrator, a website (<img src="…svg">), Google Slides, Keynote, or Office. Never blurs, tiny file size. Use this by default.
  2. PNG — transparent raster at high resolution. Use where SVG isn't accepted: some email tools, app icon generators, social avatars, quick pastes.
  3. Pick the variant by background: -dark on light surfaces, -light on dark surfaces, the blue mark anywhere it reads.
  4. For a print shop, use an outlined lockup — the wordmark is already converted to vector shapes, so it renders identically even if the shop doesn't have the Space Grotesk font installed. Brand colors are on this sheet.
